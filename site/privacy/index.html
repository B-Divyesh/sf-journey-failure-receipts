Privacy

Journey Failure Receipts is a local npm package. It writes receipt files to the output folder you configure in your Playwright project.

Receipt content

The package captures the evidence you configure for a failed assertion. Configure mask selectors for application-specific private content and protect CI artifacts under your own retention policy.

This documentation site

The site has no account system or analytics. The demo stores its sample state only under a browser key beginning with demo:. Reset demo or Start for real removes that sample state.

Contact

For a security report, use the project’s public GitHub repository without posting credentials or private receipt files.

01 / Why final reports miss the failed state

Save the page state when the assertion fails.

Later test steps can hide the broken cart or stale price. A receipt keeps the evidence from the failed step.

  1. RunRun the Playwright assertion you already use.
  2. SaveMask selected data and save evidence when it fails.
  3. ContinueRecord the soft assertion failure and keep the test flow running.

03 / What each failure receipt contains

The details needed to find the test failure.

  • 01

    Masked screenshot

    A screenshot with form fields and elements matched by configured selectors masked.

  • 02

    Page structure

    A selected page section with private values removed.

  • 03

    Recent messages

    Recent warnings and errors that help explain the failure.

  • 04

    Request summary

    Method, status, type, and duration without request bodies.

  • 05

    Failure context

    The test, page, time, and failure message in one HTML receipt.

04 / Install the Playwright fixture

Wrap a soft assertion that needs a receipt.

Use expect inside receipt.soft. It saves evidence, records the soft assertion failure, and lets the test continue.

fixtures.ts + test.spec.ts
// fixtures.ts
import { createReceiptTest, expect } from 'journey-failure-receipts/playwright';

export const test = createReceiptTest({
  maskSelectors: ['[data-private]'],
  domSelector: 'main',
});

// test.spec.ts
test('add to cart', async ({ page, receipt }) => {
  await receipt.soft('Cart count increments', async () => {
    await expect(page.getByTestId('cart-count')).toHaveText('1');
  });
});
